OptiData Analytics

Es un proyecto de análisis comercial desarrollado utilizando SQL sobre la base de datos Northwind.

El proyecto tiene como objetivo analizar información de clientes, pedidos, ventas, productos y categorías para identificar patrones y generar información útil para la toma de decisiones comerciales.

OBJETIVOS: Aplicar SQL para realizar un análisis exploratorio y comercial de una base de datos, utilizando consultas para:

Validar la calidad de los datos.
Analizar el comportamiento de los clientes.
Segmentar clientes según su nivel de compra.
Analizar la evolución de las ventas.
Identificar las categorías y productos con mayores ventas.
Obtener indicadores clave de desempeño (KPIs).


Las principales bases de datos que utilice fueron: Customers, Orders, Order Details, Products, Categories

Conclusiones

El análisis permitió identificar el comportamiento comercial de los clientes, la evolución de las ventas y las categorías y productos con mayor participación en las ventas.

La segmentación por valor de compra permite diferenciar clientes según su nivel de contribución comercial, mientras que el análisis de tendencias facilita la identificación de periodos de crecimiento y disminución.
